# Synthetic examples

These files are small synthetic examples used for demonstrations and regression tests. They do not contain real research data.

- `simple_fred.csv`: simple long-format FRED-style time series.
- `wide_time_imf_mock.csv`: IMF BOP/PIP-style wide time-period columns; `SCALE.ID` is an attribute, not the value column.
- `wide_measure_epu_mock.xlsx`: EPU-style wide measure columns keyed by `Year × Month`.
- `report_style_worldbank_mock.xlsx`: World Bank-style report worksheet with title/notes before the real header.
